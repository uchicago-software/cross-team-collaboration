# Cross Team Collaboration

This repository is used to match people across teams at the University of Chicago who are interested in collaboration.

## Code Review

If you would like to swap code review with another team, [create an issue with this form](https://github.com/uchicago-software/cross-team-collaboration/issues/new?template=review.yaml&label=unmatched).
If you see an open issue you would like to pair with, assign yourself and reach out to the original poster.


## Planning Session

If you would like to shadow another team's planning/pointing/scoping session, [create an issue with this form](https://github.com/uchicago-software/cross-team-collaboration/issues/new?template=planning.yaml&label=unmatched).
If you see an open issue you would like to pair with, assign yourself and reach out to the original poster.
